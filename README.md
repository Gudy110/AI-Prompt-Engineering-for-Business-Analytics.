# AI Prompt Engineering for Business Analytics

## Overview
This repository contains my Week 2 assignment on AI prompt engineering 
using the RCTFCE framework, applied to a real business scenario involving 
a retail company with 30 stores experiencing 18 months of declining performance.

## Contents
- **AI Prompt Engineering for Business Analytics assignment.docx** — Full assignment submission containing:
  - Part A: RCTFCE Prompt
  - Part B: AI-Generated Stakeholder Brief for the CEO
  - Part C: Reflection

## Assignment Summary
A retail company provided a dataset of approximately 50,000 records covering 
store performance, product sales, customer transactions and loyalty programme 
activity. Using the RCTFCE framework, I designed an AI prompt to investigate 
the causes of declining performance and identify opportunities for improvement.
